# Manufacturing Operations Insights Power BI Dashboard

A Power BI dashboard designed to monitor manufacturing operations. This dashboard provides end-to-end visibility into production efficiency, costs, quality, and machine performance, enabling data-driven decisions to improve throughput and reduce waste.

Key Features & Metrics:

- Track overall production performance and efficiency.

- Measure machine and operator shifts efficiency.

- Monitor material, labor, and energy costs.

- Identify quality issues and process improvements.

- Monitor units produced, maintenance and downtime impact.

- Evaluate workforce performance.

Built with Power BI, it provides interactive visuals and trend analysis to drive actionable insights in modern manufacturing environments.
